# Project Brief — majumotor-web

## Description
Website company profile + portal admin PT Maju Motor — klien fiktif untuk project training internal LOGIQUE.

## Core goals
- Company profile publik: lineup mobil, hero section, informasi dealer
- Portal admin: staff dealer dapat login dan mengelola data booking test drive
- Semua fitur dikerjakan per tiket Logitask (project TMM — TRAINING Maju Motor)

## Target users
- **Publik** — calon pembeli mobil (akses company profile)
- **Staff dealer PT Maju Motor** — akses portal admin via login

## V1 scope
- [x] Company profile homepage (lineup mobil)
- [x] Staff authentication (login, logout, route protection)
- [ ] Form booking test drive (publik)
- [ ] Daftar booking di portal admin (staff)

## Out of scope (explicit)
- UI untuk buat/kelola akun staff (akun di-seed developer)
- Fitur lupa password / reset password
- Multi-role atau permission level
- Login via SSO / third-party
- E-commerce / transaksi online
